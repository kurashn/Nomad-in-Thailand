---
description: Deploy Next.js to Vercel and configure MuuMuu Domain
---

このワークフローでは、GitHubにあるNext.jsプロジェクトをVercelにデプロイし、ムームードメインで取得した独自ドメイン (`nomad-place-jpn.com`) を接続する手順を説明します。

## 手順 1: Vercelへのデプロイ

1.  [Vercel](https://vercel.com/) にアクセスし、GitHubアカウントでログイン（またはサインアップ）します。
2.  ダッシュボードの **"Add New..."** ボタンをクリックし、**"Project"** を選択します。
3.  **"Import Git Repository"** の一覧から `Nomad-Place` を探し、**"Import"** ボタンをクリックします。
4.  **"Configure Project"** 画面が表示されます。
    *   **Framework Preset:** `Next.js` が自動選択されているはずです。
    *   **Root Directory:** `./` (そのままでOK)
    *   **Environment Variables:** 特に設定していなければそのままでOK。
5.  **"Deploy"** ボタンをクリックします。
    *   デプロイが完了するまで1〜2分待ちます。
    *   画面に花吹雪が舞い、"Congratulations!" と表示されればデプロイ成功です。

## 手順 2: Vercelでのドメイン設定

1.  デプロイ完了後のダッシュボード画面（またはプロジェクトのトップ画面）で、**"Settings"** タブをクリックします。
2.  左メニューから **"Domains"** を選択します。
3.  入力欄に `nomad-place-jpn.com` と入力し、**"Add"** をクリックします。
4.  **"Recommended"** のオプション（通常は `nomad-place-jpn.com` と `www.nomad-place-jpn.com` の両方を設定）を選択し、**"Add"** を押します。
5.  画面に **"Invalid Configuration"** や **"Nameservers"** のエラーが表示されますが、正常です。ここに表示される **Aレコード** と **CNAMEレコード** の情報をメモします。
    *   通常、Aレコードの値は `76.76.21.21` です。
    *   CNAMEレコード (www) の値は `cname.vercel-dns.com` です。

## 手順 3: ムームードメインでのDNS設定 (詳細版)

Vercelで表示された「Aレコード」と「CNAMEレコード」を、ムームードメインに設定します。
**※この作業が一番の山場です。慎重に行いましょう。**

1.  [ムームードメインのコントロールパネル](https://muumuu-domain.com/?mode=conpane) にログインします。
2.  左サイドバーのメニューから、**[ドメイン管理]** > **[ドメイン操作]** > **[ムームーDNS]** をクリックします。
3.  取得したドメイン (`nomad-place-jpn.com`) の右側にある **[変更]** ボタンをクリックします。
4.  **「設定2」** という項目を探してください（画面の下の方にあります）。
    *   ※「設定1 (ムームーメール等)」は使いません。
    *   **[設定2を利用する]** というラジオボタンや、**[カスタム設定]** ボタンがある場合はそれを選択します。

5.  **「設定2」の表に、以下の2行を入力します。**

    ### 1行目 (Aレコードの設定)
    *   **サブドメイン:** 「(空欄のまま)」 ※何も入力しないでください！
    *   **種別:** `A` を選択
    *   **内容:** `76.76.21.21` (VercelのAレコードの値)
    *   **優先度:** (入力不要)

    ### 2行目 (CNAMEレコードの設定)
    *   **サブドメイン:** `www` と入力
    *   **種別:** `CNAME` を選択
    *   **内容:** `cname.vercel-dns.com` (VercelのCNAMEレコードの値)
    *   **優先度:** (入力不要)

6.  入力が終わったら、画面一番下の **[セットアップ情報変更]** ボタンをクリックします。
7.  「設定を変更しました」と出ればOKです。

## 手順 4: 反映の確認

1.  Vercelの **Domains** 設定画面に戻ります。
2.  DNS設定が世界中に反映されるまで、最大で24時間程度かかる場合があります（通常は数分〜1時間）。
3.  Vercelの画面でドメインの横に **チェックマーク** が付けば接続完了です。
4.  ブラウザで `https://nomad-place-jpn.com` にアクセスし、サイトが表示されることを確認します。
